# Parity — U8 (inventory, windows, creative & item use)

U8 delivers the server-authoritative inventory: the Java-layout windows (`bot.inventory`, `bot.currentWindow`) kept in
sync with the Bedrock containers, `clickWindow` emulated with item stack requests (lib/bedrock/click.js,
lib/bedrock/inventory_model.js, lib/bedrock/stack_request.js), the window registry with the slot maps of every container
type (lib/bedrock/windows.js, lib/bedrock/slots.js), container opening, held item, item use, creative mode and the
vendored upstream plugins (inventory, simple_inventory, chest, creative). Unit tests run on a fake client;
`test/external/*` against BDS 1.26.51.1. `adapted` rows link [docs/differences/U8.md](../differences/U8.md).
