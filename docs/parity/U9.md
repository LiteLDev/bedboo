# Parity — U9 (player state, world extras & dimensions)

U9 delivers health / food / death and the 3-step respawn (`bot.respawn`, `respawn` option), experience, world time
(world clocks), weather, spawn point, abilities, oxygen, the game state extras (game rules, credits), block actions
(note blocks, pistons, chests, break progress), block entities (`blockEntityData`, signs, `updateSign`),
`setCommandBlock`, the vendored `ray_trace` / `explosion` plugins, bed state (`isABed`, `parseBedMetadata`,
`spawnReset`, `isSleeping`) and the dimension flow (`/execute in`, nether / end portals, End exit + credits, respawn
into another dimension). External suites run against BDS 1.26.51.1 (`packages/mineflayer-bedrock/test/external/`);
Bedrock extras without an upstream counterpart: `dimensionTravel`, `blockActions`, `blockEntities`, `health`,
`playerState`. Unit tests replay the recorded join (`test/unit/{health,dimension,weather,bed,player_state,block_actions}.test.js`).
The upstream `sign` test (owner U11) is ported in `test/external/sign.test.js` (runs since `bot.placeBlock` landed). `adapted` / `n.a.` rows link [docs/differences/U9.md](../differences/U9.md) (or U4's entries for the game
fields U4 started).
