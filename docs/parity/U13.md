# Parity — U13 (stations)

U13 delivers the station plugins: `furnace.js` (furnace, blast furnace and smoker), `enchantment_table.js`,
`anvil.js` and `villager.js` (villagers and wandering traders, `bot.trade`). They are vendored from mineflayer 4.39.0
with Bedrock packet layers: `container_set_data`, `player_enchant_options`, `update_trade`, and item stack requests
`craft_recipe` / `optional` + `consume` + `place` from `creative_output`. Shared code lives in
`lib/bedrock/stations.js` and the Bedrock anvil rules in `lib/bedrock/anvil.js`.

The external suites run against BDS 1.26.51.1: `furnace`, `enchanting`, `anvil` and `trade`, plus Bedrock extras in
the same files. Unit tests on a fake client are in `test/unit/stations.test.js`; upstream has no internal tests for
the stations. Results the server never sends back (enchanted, anvil and trade items) are predicted, and the e2e
suites compare each prediction with the server's copy after an inventory resend. `adapted` / `n.a.` rows link
[docs/differences/U13.md](../differences/U13.md).
