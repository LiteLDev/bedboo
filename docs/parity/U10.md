# Parity — U10 (digging)

U10 delivers `lib/plugins/digging.js` (vendored from mineflayer 4.39.0, Java's `block_dig` replaced by Bedrock
server-authoritative block actions) and `lib/bedrock/dig_speed.js` (the Bedrock break speed, every factor measured on
BDS 1.26.51.1). External suites run against BDS (`packages/mineflayer-bedrock/test/external/`): `digWaterSpeed`
(verbatim + a Bedrock extra), `digEverything` (adapted: `/setblock` staging, fastest tool, skipped blocks listed),
and the Bedrock extras `digOres` (every ore / stone / wood / soil family × hand and each tool tier, Efficiency, Haste,
Conduit Power, Mining Fatigue, under water ± Aqua Affinity, in the air; BDS' break speed = ours, no restoration,
drops, timing, durability) and `digging` (events, stopDigging, creative, back-to-back digs, the released break state,
faces, durability, death, what other players see). The upstream `digAndBuild` test is U11's / U16's row
(`test/external/digAndBuild.test.js`, verbatim; it runs now that `bot.dig` exists and passes with this unit's dig).
Unit tests: `test/unit/digging.test.js`. `adapted` rows link
[docs/differences/U10.md](../differences/U10.md).
