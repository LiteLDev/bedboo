# Parity — U15 (ecosystem plugins & examples)

U15 runs the mineflayer ecosystem plugins on mineflayer-bedrock with small `pnpm patch`es
(`patches/mineflayer-{pathfinder,tool,collectblock,armor-manager,auto-eat,pvp}@*.patch`), ports mineflayer 4.39.0's
`examples/` to `packages/mineflayer-bedrock/examples/` (workspace package `@bedboo/examples`) and the upstream
example tests. Ecosystem suites run on BDS in survival; the pathfinder and collectblock suites on the seeded default
world "2" ([docs/ecosystem.md](../ecosystem.md#test-world)). Unit tests: `test/unit/ecosystem.test.js`,
`test/unit/examples.test.js`. `adapted` rows link [docs/differences/U15.md](../differences/U15.md).

`packages/mineflayer-bedrock/test/unit/examples.test.js` › "every example parses and resolves the modules it loads
