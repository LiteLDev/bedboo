# Parity — U2 (Bedrock data layer)

U2 owns no plugin; it provides the data every plugin reads (`bot.registry` is `bedrock_1.26.51` with the
@bedboo/bedrock-data overlay and the patched prismarine-registry/-chunk/-block/-item) and the
`supportFeature` table. Data correctness is asserted by unit tests on the U0 BDS capture plus a live check
against BDS 1.26.51.1 (overworld, nether, end; `packages/bedrock-data/scripts/live-check.js`).

| item | kind (property/method/event/test/export) | owner | status (todo/done/adapted/n.a.) | asserting test |
|---|---|---|---|---|
| `bot.supportFeature` | method | U4 → U2 | adapted | `packages/mineflayer-bedrock/test/unit/data/features.test.js` › "has an explicit Bedrock value for every feature name used upstream", "takes the deliberate Bedrock branches", "unknown names: strict mode throws, default mode warns once and returns false" — see [differences: feature table](../differences/U2.md#feature-table) |

Data behind `bot.registry` (the `bot.registry` row itself belongs to U4) and where it is asserted:

- Block names/ids/states; all 22,091 states hash to the BDS runtime ids (CloudburstMC palette, same order):
  `packages/bedrock-data/test/data.test.js` › "every block state hashes to the CloudburstMC runtime id at the
  same palette index". Differences: [registry](../differences/U2.md#registry), [state ids](../differences/U2.md#state-ids).
- Registry from `start_game` + `item_registry` (items by network id, `blocksByRuntimeId`,
  `runtimeIdByStateId`, item-id re-keying of harvestTools/materials/foods/drops):
  `packages/mineflayer-bedrock/test/unit/data/registry.test.js`.
- `level_chunk` (sub-chunk request mode) + `subchunk` decoding, flat-world layers, byte-exact re-encoding,
  zero-bit palettes with negative hashes, unknown-id placeholder: `packages/mineflayer-bedrock/test/unit/data/chunk.test.js`;
  live: every sub-chunk of a default-generated overworld, the nether and the end decodes and re-encodes.
- `Block.fromStateId` / `digTime` / `canHarvest` / `hash` / per-state collision shapes:
  `packages/mineflayer-bedrock/test/unit/data/block.test.js`.
- `Item.fromNotch` / `toNotch` (ItemV4, full empty item, `block_runtime_id`, stack ids):
  `packages/mineflayer-bedrock/test/unit/data/item.test.js` (every captured inventory packet re-serializes byte
  for byte; every creative item gets the block runtime id BDS uses).
- Effects, foods, attributes, enchantments, entities, particles, sounds: `packages/bedrock-data/test/data.test.js`;
  differences: [datasets](../differences/U2.md#datasets).
- One patched copy of every data package for mineflayer, pathfinder, collectblock, pvp, tool:
  `packages/mineflayer-bedrock/test/unit/data/resolve.test.js`.
- Overlay injection before anything loads `bedrock_1.26.51` (and in-place refresh if something did):
  `packages/bedrock-data/test/install.test.js`.
