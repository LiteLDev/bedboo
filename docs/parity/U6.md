# Parity — U6 (chat, commands & HUD)

U6 completes the chat plugin on U4's core (chat patterns, `chat` / `whisper`, `awaitMessage`, `actionBar`,
`unmatchedMessage`, `whisper`, client-side `tabComplete` from `available_commands`), moves the Bedrock text parser to
`lib/bedrock/text.js` (all text types, rawtext, `%key`, Bedrock `§` codes), and implements the HUD plugins: titles,
boss bars (summoned bosses), scoreboards, sounds, particles (`Particle` adapted), with teams and the tab-list
header/footer kept as documented empty values. Unit tests use recorded / probed BDS 1.26.51.1 packets; the
`test/external/*.test.js` suites are the upstream external tests ported against a real BDS. `adapted` / `n.a.` rows
link [docs/differences/U6.md](../differences/U6.md). Not U6's: `noteHeard` (U9, block_actions) — the noteHeard part of
the upstream `sound` test is `sound.test.js` › "sound noteHeard" (runs since U9 landed; U16a removed the skip); the
`Particle` export row stays U4's (the export now points at U6's adapted class, see
[differences: particles](../differences/U6.md#particles)).
