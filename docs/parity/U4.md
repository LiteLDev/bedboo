# Parity — U4 (core runtime)

U4 delivers the runtime every other unit builds on: `createBot` / the loader, the bedrock-protocol client wrapper,
the registry wiring, the lifecycle (the only `spawn` emitter), the tick clock + `player_auth_input` queue, the
stationary physics stub with the full physics surface (U5 replaces the engine), the local player entity, the world
core (chunks in sub-chunk request mode, block updates, findBlocks), the chat core, game / settings / kick and
resource packs. Unit tests replay the recorded BDS 1.26.51.1 join (`test/fixtures` `join_flat`) into a fake client;
the `test/external/core*.test.js` and `resourcePack.test.js` suites run against a real BDS (Bedrock extras, no
upstream test of the same name). `adapted` / `n.a.` rows link [docs/differences/U4.md](../differences/U4.md).
`bot.supportFeature` (U4 → U2) is listed by U2.
