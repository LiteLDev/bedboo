# Parity — U12 (crafting)

U12 delivers crafting: the server's `crafting_data` as prismarine-recipe `Recipe`s (lib/bedrock/recipes.js, item tags in
lib/bedrock/item_tags.js), `bot.recipesFor` / `bot.recipesAll` with upstream's semantics, a Java-shaped
`bot.registry.recipes`, and `bot.craft` in the 2×2 grid and at a crafting table as Bedrock item stack requests
(lib/plugins/craft.js, vendored from mineflayer 4.39.0). Unit tests run on the recorded crafting_data and a fake client;
`test/external/crafting*.test.js` against BDS 1.26.51.1. `adapted` rows link [docs/differences/U12.md](../differences/U12.md).
