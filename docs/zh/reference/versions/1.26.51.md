# 基岩版 1.26.51

1.26.51 协议族（默认版本）的说明：**协议 2193**，BDS **1.26.50.5**、**1.26.51.1** 与 **1.26.52.3**。向
`createBot` 传入 `version: '1.26.51'` 或其中任一 BDS 版本（不传或传 `false` 即为 1.26.51），此时 `bot.version` 为
`'1.26.51'`，`bot.protocolVersion` 为 2193。除非页面另有说明，本参考的其余内容均针对此协议族（参见
[BDS 笔记](../bds.md) 与 [连接与版本](../differences/connection.md#versions)）。

## 数据 {#data}

`@bedboo/bedrock-data` 提供 `data/1.26.51/`，由 `scripts/generate.js --version 1.26.51` 根据
`scripts/sources.js` `PINS['1.26.51']` 固定的来源与实机探测结果 `scripts/probe/1.26.51.json`（BDS 1.26.51.1）生成：
22 091 个方块状态、2 076 个物品、89 个原版生物群系。来源列在该包的 `NOTICE.md` 中。

## 三个 BDS 版本共用一套数据 {#builds}

三个 BDS 版本的协议与游戏数据相同。每个版本都以原生方式启动，以 `version: '1.26.51'` 加入，并将加入时的静态数据
与生成数据所用的 BDS 1.26.51.1 对比：

| 对比项 | 1.26.50.5 | 1.26.52.3 |
|---|---|---|
| `start_game`：方块调色板校验和、`block_network_ids_are_hashes`、98 个 `block_properties`、实验性玩法、游戏规则 | 相同 | 相同 |
| `item_registry`：2 076 个物品，运行时 id、`component_based` 与版本均相同 | 相同 | 相同 |
| `creative_content`：124 个分组、1 980 个条目 | 相同 | 相同 |
| `biome_definition_list`：89 个定义 | 相同 | 相同 |
| `crafting_data`：每个配方及其网络 id（每次运行随机的配方 UUID 除外） | 相同 | 相同 |
| `available_entity_identifiers`、`voxel_shapes`、`trim_data`、`camera_presets`、`unlocked_recipes` 等 | 相同 | 相同 |
| `available_commands`：82 个命令、其重载、参数类型 id 与枚举内容 | 相同 | 相同 |
| 探测：状态效果 id、附魔 id、生物群系顺序、实体碰撞箱 | 相同 | 相同 |

仅有的差异都在服务端或不影响行为：

- `start_game.engine` 为各自的版本（`1.26.50`、`1.26.52`）。
- `available_commands` 中 `/place feature` 的世界生成特征名顺序不同（名称相同）；bedboo 通过每个数据包自带的值表解析
  枚举值，不依赖顺序。
- BDS 1.26.50.5 发送的 `jigsaw_structure_data` 模板池不同（结构生成，bedboo 不使用）。

因此 `data/1.26.51/`、特性表与命令类型 id 同时适用于这三个版本，不存在针对单个 BDS 版本的表。bedboo 也在每个版本上
实际运行过（生成、注册表、`blockAt`、物品栏、聊天、物理行走、挖掘、放置、实体跟踪、Tab 补全、断开连接），没有差异。

## 测试 {#tests}

`pnpm test` 针对此协议族运行单元测试（`BEDBOO_VERSION=1.26.51` 或 `BEDBOO_VERSION=1.26.52.3` 等 BDS 版本可显式选择）。
其加入抓包为 `test/fixtures/1.26.51/join_flat`（BDS 1.26.51.1）。
